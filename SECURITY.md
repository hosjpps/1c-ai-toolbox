# Безопасность

## Данные заказчиков

- **Персональные данные клиентов** (ФИО, телефоны, адреса, долги, паспорта) моделям не отдавать — 152-ФЗ, и это риск заказчика, а не наш. Касается и скриншотов форм со списками, и выгрузок данных, и результатов запросов через MCP.
- **Выгрузка конфигурации** (метаданные и код) данных не содержит, её можно давать агенту. Перед этим — поиск по выгрузке паролей, ключей, адресов серверов: программисты заказчика кладут их в константы и тексты модулей.
- **Живые данные базы** — только на тестовой копии и только через обезличивание (см. «Обезличивание» в [catalog/gaps.md](catalog/gaps.md)). У MCP-серверов в каталоге поле «Доступ к данным»: `code-metadata` — безопасно, `live-data-read` — риск ПДн, `writes-infobase` — запись.

## Базы

- **Рабочая база — только чтение.** Никаких `db-load`, `db-update`, загрузки расширений, выполнения кода, обменов из агента. Изменения доходят до рабочей базы только файлом (`.cfe`, `.cf`) руками человека после проверки на тестовой копии.
- В тестовой копии бывают узлы обмена, которые смотрят на боевые системы (сайт, банк). Перед запуском обмена в тесте — проверить, куда он пойдёт.
- Пароли к базам не записывать в конфиги инструментов открытым текстом (`.v8-project.json`, `v8project.local.yaml` и т.п.) и не передавать аргументом командной строки там, где можно иначе.

## Чужие инструменты

Почти всё в каталоге — молодые проекты одного-двух авторов. Перед установкой:

- **Хуки Claude Code** (`hooks.json`, SessionStart/PreToolUse) выполняются сами — прочитать каждый. Пример из каталога: `claude-code-bsl-lsp` на старте сессии скачивает бинарник BSL LS из GitHub Releases без проверки хеша.
- **Скачиваемые бинарники** (Unica, code-index-mcp и др.) — откуда качаются, проверяется ли хеш, можно ли собрать из исходников.
- **Сеть:** что инструмент отправляет наружу. Unica, например, по запросу документации ходит на `ai.v8std.ru` с текстом запроса — отключается в его настройках.
- **Лицензии:** MIT/Apache/MPL — без вопросов. GPL/AGPL/LGPL — для своей работы можно, но код из них нельзя переносить в закрытые разработки заказчика. Без лицензии — формально использовать нельзя, только как образец идей.
- **Наборы правил** проверять по существу: в одном популярном архиве правил нашлись две ошибки по платформе (`ПродолжитьВызов()` «обязателен» в `&ИзменениеИКонтроль`, `НачалоТранзакции()` вместо `НачатьТранзакцию()`). Агент по таким правилам пишет неработающий код.
