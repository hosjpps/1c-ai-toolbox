#### [gitsync](https://github.com/oscript-library/gitsync)

★ 343 · обновлён 2026-10-25 · лицензия MPL-2.0 · проверено скептиком, оценка понижена

Синхронизация хранилища конфигурации 1С с git-репозиторием в формате выгрузки Конфигуратора.

- **Работает:** OneScript; для выгрузки нужен Конфигуратор 1С (Windows или Linux), на macOS только через удалённый сервер/контейнер
- **Нужно:** OneScript, платформа 1С, доступ к хранилищу (путь, логин/пароль), git; для больших хранилищ — сервер с запасом по времени
- **Доступ к данным:** live-data-read
- **Риски:** Читает хранилище заказчика; пароль — только через env, не флагами (попадает в историю shell и список процессов); отдельная учётка только на чтение. В git уходит код заказчика: приватный репозиторий, проверка на ПДн и пароли. Выгрузка истории идёт часами; нужен Конфигуратор/платформа (на macOS только на удалённом Windows/Linux).
- **Почему такая оценка:** Основной способ перевести заказчика с хранилища 1С на git без потери истории; очень частая задача на старте проекта. Живой (push 2026-10-25). Нужен там, где у заказчика есть хранилище.
- **Проверка:** gh api: 343 звезды, push 2026-10-25, MPL-2.0, не archived. README подтверждает: односторонняя синхронизация хранилища в git; логин и пароль хранилища передаются флагами --storage-user/--storage-pwd (в README примеры с паролем открытым текстом в командной строке) либо через env GITSYNC_STORAGE_USER/PASSWORD. Нужна только там, где у заказчика есть хранилище конфигурации; это не почти каждый проект, поэтому core -> useful.
- **Версия на дату проверки:** `dd70547174fa` (2026-10-25)
