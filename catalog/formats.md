#### [saby-integration/v8unpack](https://github.com/saby-integration/v8unpack)

★ 116 · обновлён 2026-10-23 · лицензия MIT · проверено скептиком

Python (pip install v8unpack, requires-python >=3.7, единственная зависимость tqdm): распаковка и сборка бинарных cf/cfe/epf без платформы 1С в json-дерево с .bsl-файлами отдельно; предназначен для git-хранения исходников.

- **Работает:** Python >=3.7 (зависимость tqdm), OS Independent, macOS подходит; есть и exe для Windows
- **Нужно:** Бинарный .cf/.cfe/.epf (выгрузка с Windows-машины заказчика); для тяжёлых конфигураций 64-битный Python последних версий
- **Доступ к данным:** code-metadata
- **Риски:** Формат хранения собственный (json), не совместим с XML Конфигуратора и EDT, поэтому результат нельзя напрямую вернуть в XML-процессы. Обратную сборку (-B) проверять загрузкой в тестовую базу. cf с данными заказчика только обезличенно. Формулировка про «единственный живой» завышена: рядом есть обёртки (v8unpack-mcp, v8unpack-agent), но самостоятельной альтернативы для Mac без платформы действительно нет. Если в проекте уже есть XML-выгрузка, инструмент не нужен.
- **Почему такая оценка:** Единственный живой инструмент, который на Mac без платформы превращает cf/cfe/epf в читаемые исходники и собирает обратно; в экосистеме на нём строятся другие инструменты (1c-form-tools, v8unpack-agent), а PyPI-пакет называется v8unpack именно у них.
- **Проверка:** gh api: 116★, push 2026-10-23, MIT, не archived. README и pyproject совпадают с описанием (json, код отдельно, OS Independent, exe-сборка только под Windows). Core оставлен только из-за среды владельца (Mac, платформа на удалённой Windows, на руки приходят cf/cfe/epf); для проектов с XML-выгрузкой это useful. Последний тег релиза называется «Last» (март 2026), привязывать версии по тегам нельзя — фиксировать по коммиту.
- **Версия на дату проверки:** `deba8926fab7` (2026-10-23)

- **Проверка:** Описание подтверждено README. Остаётся useful: готовые XSD дёшево проверяют XML от агента до загрузки в базу, никаких данных не трогает.
