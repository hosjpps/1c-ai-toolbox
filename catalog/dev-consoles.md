## Брать почти всегда

#### [cpr1c/tools_ui_1c (Универсальные инструменты 1С)](https://github.com/cpr1c/tools_ui_1c)

★ 1151 · обновлён 2026-11-05 · лицензия GPL-3.0 · найдено при доборе пропусков, скептик не проверял

Бесплатное открытое расширение (UI.cfe) с набором инструментов для управляемых форм: консоль запросов (форк RequestConsole9000), консоль кода, консоль отчётов/СКД, редактор СКД для тонкого клиента, редактор объекта, консоль HTTP-запросов и веб-сервисов, структура хранения, группповая обработка, сравнение объектов.

- **Работает:** Расширение платформы 1С 8.3.12+ (Windows/Linux x86/x64; на macOS заявлено «должно работать, не тестировалось»), тонкий/толстый клиент. Ставится на стороне сервера 1С, не на Mac.
- **Нужно:** Доступ к тестовой копии базы заказчика на Windows-сервере, право подключить .cfe-расширение, платформа 8.3.12+. Расширение, а не внешняя обработка, поэтому конфигурация с поддержки не снимается.
- **Доступ к данным:** writes-infobase
- **Риски:** Содержит инструменты записи (редактор объекта, групповая обработка, удаление помеченных, загрузка данных) и консоль кода с выполнением произвольного кода: в рабочую базу не ставить, только в тестовую копию или под ограниченной ролью. Результаты запросов видят живые данные (ПДн), моделям их не отдавать. Часть форков с «разрешением автора» вместо лицензии.
- **Почему такая оценка:** Самый живой и популярный бесплатный набор: 1151 звезда, релиз v26.6.1 (2026-06-01), push 2026-11-05, GPL-3.0. Одним расширением закрывает консоль запросов, СКД-консоль и консоль кода без платной лицензии и без правки конфигурации.
- **Версия на дату проверки:** `590e1b6efbb5` (2026-11-04)

★ 113 · обновлён 2026-11-02 · лицензия нет · платно/закрыто · найдено при доборе пропусков, скептик не проверял

Коммерческий набор инструментов разработчика на управляемых формах: консоль запросов (отладка пакетов с временными таблицами, анализ планов, дерево результатов), консоль СКД, консоль кода, улучшенный конструктор запросов и СКД для тонкого клиента, редактор объекта, метаданные, поиск ссылок, анализ прав, регламентные задания, монитор лицензий. Поддержка 1С 8.5.

- **Работает:** Расширение платформы 1С 8.3/8.5, Windows-серверы 1С; лицензия оформляется на сервер 1С (1 сервер = 1 лицензия = 1 ключ).
- **Нужно:** Покупка лицензии на Инфостарт (PROF до 7 пользователей, CORP — больше; по странице маркетплейса цены от единиц до десятков тысяч рублей, точная цена нужной версии не проверена), установка на сервер 1С заказчика, согласие заказчика.
- **Доступ к данным:** writes-infobase
- **Риски:** Платно и закрыто, исходники в репозитории не хранятся («Проект для сбора обратной связи»), лицензия в API null. Лицензия привязана к серверу заказчика, под каждый проект отдельная покупка. Есть инструменты записи в базу. Перед покупкой сверить текущие цены и условия.
- **Почему такая оценка:** Самый мощный, но платный и закрытый продукт, а репозиторий — только трекер обратной связи без исходников. Бесплатные tools_ui_1c и ИР закрывают большую часть задач, поэтому не core, но для постоянных клиентских проектов с СКД-отладкой может окупиться.
- **Версия на дату проверки:** `715e5d49c7c5` (2026-09-22)

## Под конкретную задачу

#### [pulh1/QueryConsole1C (консоль с исполняемыми представлениями для ЗУП)](https://github.com/pulh1/QueryConsole1C)

★ 79 · обновлён 2026-11-05 · лицензия MIT · найдено при доборе пропусков, скептик не проверял

Открытое расширение (проект EDT, MIT): консоль запросов с собственным лексером/парсером и расширением языка запросов — «исполняемые представления», которые превращают методы программного интерфейса ЗУП/ЗГУ/ERP во временные таблицы внутри пакетных запросов; есть конструктор запросов и генерация кода.

- **Работает:** Расширение 1С 8.3 (.cfe, релиз beta 0.5.0.1), исходники в формате EDT; Windows-платформа.
- **Нужно:** ЗУП/ЗГУ/ERP-конфигурация, подключение .cfe в тестовой базе.
- **Доступ к данным:** live-data-read
- **Риски:** Бета-версия (0.5.0.1), заточена под зарплатные конфигурации. Исполняемые представления вызывают методы ПИ, которые могут иметь побочные эффекты — читать код перед запуском. Данные ЗУП — персональные.
- **Почему такая оценка:** Нужна только на проектах ЗУП/ЗГУ/ERP; в остальных случаях не нужна. Интересна как пример разбора языка запросов на самой 1С и как репозиторий с AGENTS.md и тестами на Vanessa.

#### [SgonnovDmGit/lensa-query-console (Линза)](https://github.com/SgonnovDmGit/lensa-query-console)

★ 17 · обновлён 2026-11-04 · лицензия NOASSERTION · найдено при доборе пропусков, скептик не проверял

Бесплатная внешняя обработка .epf: консоль запросов с ИИ-агентом, который читает метаданные конфигурации и собирает запрос по вашим регистрам; текст запроса виден до выполнения, строки результата агент не читает; умеет оформить готовый запрос во внешний отчёт .erf или обработку .epf.

- **Работает:** Платформа 1С 8.3.16+, управляемые формы, БСП; внешняя обработка .epf, Windows-серверы заказчика.
- **Нужно:** Релиз .epf с GitHub, подключение через дополнительные отчёты и обработки БСП, свой API-ключ ИИ-провайдера в настройках.
- **Доступ к данным:** network-external
- **Риски:** Метаданные конфигурации уходят внешнему ИИ (структура базы заказчика; по README строки данных не читаются, это не проверялось по коду). Лицензия: бесплатно и бессрочно, в т.ч. коммерчески, но «не open source», права у ИП; запрещено распространять изменённые сборки под тем же именем. Новый проект, возможна нестабильность.
- **Почему такая оценка:** Интересная идея «запрос по метаданным без выдумывания таблиц», но продукт молодой (17 звёзд), проприетарный (не open source) и завязан на внешний LLM по вашему ключу. Для нашей агентной разработки Claude Code с выгрузкой XML полезнее та же идея через MCP/навыки; брать как референс или быстрый инструмент консультанта.

- **Почему такая оценка:** Известный в сообществе источник экспертизы по производительности, но это закрытый облачный сервис с регистрацией: тексты запросов клиента уходят наружу, и работает он только с MS SQL. Годится для разовых случаев, не для инструментальной коробки.
