- **Почему такая оценка:** Официальный, самый живой (push в день проверки), read-only, работает по исходникам без запуска 1С. Закрывает и диагностику, и часть справки платформы в одном JAR.
- **Проверка:** gh api: 501 звезды, push 2026-11-07, не archived, лицензия NOASSERTION, но COPYING.md содержит LGPL-3.0 (подтверждено). Релизы с MCP: v1.1.0-rc.1..rc.8 (prerelease), последний стабильный v1.0.7 (2026-08-08) без MCP, это подтверждено. Тир core оставлен ради самого BSL LS как линтера (в каждый 1С-проект); сам MCP-режим считать экспериментальным и брать pre-release. Утверждение «ни один инструмент не меняет файлы» я не перепроверял по коду: доки лишь регистрируют рабочие папки и анализируют.
